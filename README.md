# Vy Le Portfolio

A seven-page static portfolio documenting my transition into
software engineering and current focus on backend development.

## Pages

- Home
- About Me
- Education & Experience
- My Skills
- My Projects
- My Goals
- Contact

## Technology

- Semantic HTML
- Shared vanilla CSS
- Minimal vanilla JavaScript
- Space Grotesk
- JetBrains Mono

## Run locally

Open `index.html` directly in a browser or use a local development
server such as the VS Code Live Server extension.

## Current status

The projects shown in this portfolio are planned learning projects.
They describe intended learning outcomes rather than completed
production systems.

The contact form validates input locally but does not transmit or
store messages.

## Language

English is currently supported. A Vietnamese version is planned.
